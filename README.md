# zz

一个极简的文件打包/解包小工具,单 C 文件实现,无任何第三方依赖。

## 用法

```
zz [option] <in_path> <out_path>

  -p   把文件或目录打包成一个 .zz 归档
  -u   把 .zz 归档解包到指定目录
```

## 示例

```bash
# 打包一个目录
$ ./zz -p ./mydir mydir.zz

# 打包单个文件
$ ./zz -p ./a.txt a.zz

# 解包
$ ./zz -u mydir.zz ./out
```

## 编译

```bash
gcc -std=c11 -Wall -O2 -o zz zip.c
```

## 原理

* 每个文件/目录对应一条 8KB 的头记录:4096 字节路径 + 文件大小 + atime + mtime + 权限位 + uid/gid;
* 文件数据按 512 字节对齐,末尾不足 512 字节的部分用 `\0` 补齐;
* 目录顺序先于其子项写入,解包时按顺序重建目录结构;
* 纯按位拷贝,**不压缩**,作用等价于打包/还原原始字节。

## 元数据

* 解包时会写回文件的权限、访问/修改时间,**目录的修改时间会在所有子项解出后统一恢复**,与 tar 的做法一致;
* 属主(uid/gid)也会尝试恢复,但只有具备相应权限(通常需要 root)时才会真正生效;
* ctime 由内核维护、不可手动设置,不参与恢复。

## 安全与说明

* 解包时会拒绝包含 `../` 或以 `/` 开头的路径,防止路径穿越;
* 遇到截断或损坏的归档会报错退出,不会静默写出残缺文件;
* 已知限制:路径长度上限 4096 字节;单文件打包时归档内的路径是该文件的基本名(basename)。
